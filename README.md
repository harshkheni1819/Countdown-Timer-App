# Countdown-Timer-App

A simple yet powerful web-based Countdown Timer built using **HTML**, **CSS**, and **JavaScript**. This app allows users to create and manage multiple countdowns to future events with live updates, desktop notifications, and sound alerts.

---

## Features

-  Create **multiple timers** with custom labels
-  Live countdown display in **days, hours, minutes, and seconds**
-  **Pause** and ▶️ **Resume** any timer
-  **Desktop notifications** when a countdown ends
-  Built-in alarm sound on timer completion
-  **Clear** completed timers from the interface
-  Intuitive UI and responsive layout

---

## Technologies Used

- **HTML5** – Structure and layout  
- **CSS3** – Styling and layout customization  
- **JavaScript (ES6)** – Real-time logic and interactivity  
- **Notifications API** – Desktop alerts  
- **Audio API** – Sound playback



## Permissions

This app uses the **browser Notification API**. You'll be asked to grant permission for notifications when the app loads. Notifications appear when a timer completes.
